# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-01-08

### Added
- Initial release of nextjs-seasonal-plugin
- 4 seasonal themes: Winter, Summer, Autumn, Spring
- 5 holiday themes: Christmas, Onam, Diwali, New Year, Halloween
- Custom theme support with configurable particles
- Automatic season detection based on hemisphere and date
- Smart date-based theme switching with priorities
- Full TypeScript support
- Configuration options for intensity, particle count, opacity, and colors
- SSR compatibility with Next.js
- Zero external dependencies
- Comprehensive documentation and examples
- Interactive demo application
